## 一、9个章节逐项审核

| 编号 | 章节及当前定义 | 主要审核点 | 结论 | 逐项意见/建议文字 |
| --- | --- | --- | --- | --- |
| RPT-01 | 一、审核范围：说明场地、资料、专业领域和截止时间 | 是否能防止将“未审”理解为“已通过”；范围和截止时点是否清晰 |  |  |
| RPT-02 | 二、项目与场地概况：汇总主体、地址、面积、用途、租赁条件及拟经营方案 | 事实与推断是否分离；资料来源和核验状态是否可追溯 |  |  |
| RPT-03 | 三、已取得及缺失材料：分别列示已核验、待核原件、缺失和失效材料 | 是否区分复印件/原件、已核/未核、有效/失效；缺失材料影响是否说明 |  |  |
| RPT-04 | 四、尽调检查结果：按产权、用途、消防、工程、合同、商业和运营汇总 | 检查状态的定义是否一致；待核实和不通过项是否展示备注与依据 |  |  |
| RPT-05 | 五、主要风险：列示等级、事实、依据、影响、整改措施及人工复核要求 | 风险分级是否合理；是否仅纳入人工确认结果；事实、法律/技术判断和建议是否区分 |  |  |
| RPT-06 | 六、整改与待办：列示责任人、期限、证明材料、状态和复核结论 | 整改是否可验收；关闭条件和证据是否明确；重大风险是否可被无依据关闭 |  |  |
| RPT-07 | 七、综合决策建议：由有权限人员选择推进、附条件推进、暂缓或不建议推进 | 决策责任是否归属人而非AI；决策依据、权限和时间是否完整 |  |  |
| RPT-08 | 八、推进前置条件：列示支付定金、签约或开工前必须完成的条件 | 条件是否指向时点、责任人和验收证据；是否遮盖高/重大未关闭风险 |  |  |
| RPT-09 | 九、适用边界与声明：说明资料真实性、政策时效、AI辅助性质及专业复核边界 | 免责表述是否清晰但不会不当免除管理责任；是否明示专业签章和主管部门边界 |  |  |

“结论”填：保留/修改后保留/删除/暂缓/新增项。
