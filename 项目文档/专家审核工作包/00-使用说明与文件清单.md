## 1. 工作包文件

1. `01-37项尽调清单专家审核表.md`：逐项结论、依据、意见和修改要求。
2. `02-综合报告模板专家审核表.md`：对9个报告章节及整体可用性评审。
3. `03-审核意见与修改闭环记录.md`：将专家意见转为可追踪修改项，记录复核结果。
4. `04-专家资质与独立性记录.md`：记录身份、执业范围、有效期、利益冲突和附件。
5. `05-联合评审结论与签字页.md`：专业分项结论、总体结论、限制条件和签署。

## 2. 建议审核分工

| 专业 | 建议主审范围 | 不得替代的工作 |
| --- | --- | --- |
| 法律 | 产权与出租权、租赁合同、授权、消费者条款、责任分配 | 法院/登记机关查档和针对具体交易的正式法律意见 |
| 规划/行政许可 | 证载用途、拟经营用途、改造报批、招牌和属地经营事项 | 主管部门的项目个案审批或书面答复 |
| 消防 | 原建筑消防手续、改造适用程序、疏散、设施现状和验收路径 | 消防设计、现场检测、施工质量结论和主管部门验收 |
| 建筑/结构/机电工程 | 空间几何、地面、荷载、屋面防水、供配电、照明、暖通、给排水、声学和施工条件 | 现场勘察、结构鉴定、检测试验、施工图设计和工程签章 |
| 商业/运营（建议补充） | 投资测算、收入情景、客群/竞品、运营制度、保险和会员规则 | 投资收益保证、保险承保结论或市场预测保证 |

## 3. 结论口径

每个清单项和报告章节只能选择一个结论：

- **保留**：内容、证据要求和适用范围可直接使用；
- **修改后保留**：存在不准确、不完整或不可执行之处，必须按意见修改；
- **删除**：不属于本清单范围、已失效或会造成误导；
- **暂缓/需主管部门确认**：专家无法独立得出结论；
- **新增项**：现有清单或报告存在重要缺口，应新建独立规则。

## 4. 审核质量要求

- 不接受仅填写“同意”而没有依据或适用边界的重要结论。
- 政策/规范依据应记录准确名称、发布机关、文号或条款、实施日期、适用区域及官方来源。
- 窗口咨询口径应记录部门、窗口/人员、日期、方式和回复摘要，并标记“非正式审批意见”。
- 发现现行规则与清单冲突时，应标注为高优先级修改，不得先签字后补改。
- 评审签字只确认模板和规则的专业合理性，不等于对任何具体场馆作出合规、安全或可投资承诺。

## 5. 建议流程

```text
发送待审版本和依据材料
  → 各专业独立逐项审核
  → 联合评审会处理交叉问题
  → 建立修改记录并落实
  → 修改后版本由原专家复核
  → 联合结论和分专业签字
  → 归档资质、依据、意见、修改稿和签字稿
```
